优选来源

从 Cloudflare 官方 API 实时拉取全部 IP 网段（与 CloudflareSpeedTest 默认方式相同）展开测试。覆盖最全，但单轮耗时数十分钟，适合低频深度优选。

如何获取 GitHub Token（三步）
  1. 登录 GitHub → 右上角头像 → Settings
  2. 底部 Developer settings → Personal access tokens → Tokens (classic) → Generate new token (classic)
  3. Expiration 选长期，仅勾选 gist → Generate → 复制 ghp_ 开头 Token 粘贴到上方保存。

Gist ID 在 gist 页面地址栏：gist.github.com/用户名/ID。
