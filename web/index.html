优选订阅源（每行一个 URL）

每行一个优选 IP 列表地址，支持 ip:port / 纯 IP / 带注释格式，自动去重合并为候选池。

测速端口（可多选，每端口独立测一轮）

端口越多总耗时越长（每端口一轮）。443 最常用；8443/2053/2083/2087/2096 为 Cloudflare 常见回源端口。

结果策略

每轮新冠军进前排；老上榜 IP 仍达标则保留靠后；连续 N 轮未达标才淘汰。

三档调度

区域档使用 HTTPing + -cfcolo 按真实落地机房过滤（香港 HKG、新加坡 SIN、东京 NRT、大阪 KIX 等 IATA 代码），比订阅源的"地区标注"更真实。

📘 教程：三步获取 GitHub Token（用于自动更新 Gist）
  1. 浏览器打开 github.com 并登录 → 点右上角头像 → Settings（设置）
  2. 左栏最底部 Developer settings（开发者设置）→ Personal access tokens → Tokens (classic) → Generate new token (classic)
  3. Note 随便填（如 cf-auto），Expiration 选 No expiration（永不过期）或较长有效期，勾选列表中唯一勾选框 select_scope: gist（其他全部不勾，权限最小化）→ 拉到底点 Generate token
  4. 复制生成的 ghp_ 开头的 Token（只显示一次），粘贴到本页上方"GitHub Token"输入框保存。

Gist ID 的获取：打开你的 gist 页面，地址栏 gist.github.com/用户名/这一串就是ID。
